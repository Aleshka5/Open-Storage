# ADR-0009 The owl chat returns, served by the gateway

## Status

Accepted. Supersedes [ADR-0006](0006-owl-chat-out-of-scope.md).

## Decision

`POST /api/chat` is answered by the gateway itself. The route says `chat: true` and names no upstream; the model host, key, model, and reasoning effort come from the new `llm:` block in `config.yaml`.

The port carries three packages from Auth-Service: `internal/llm` (client, prompt, node map, `<think>` filter, MLflow span), `internal/tracing` (OTLP/HTTP exporter), and `internal/chat` (the SSE handler). The prompt is `internal/llm/prompt.md`; the node map is `internal/llm/nodes.json`, generated by `npm run gen:owl-context` in `src/auth-gateway/resume-page/`.

Identity comes from the verified cookie only: the edge already has it, and the handler reads it from the request context. The client's `X-Chat-Session` is opaque log attribution and still is not a credential.

The route stays `public`. A reader who is not signed in may ask a question; one who is signed in is attributed by email in the trace.

## Rejected

A prompt and a node map in `config.yaml`. A YAML file can carry twelve hundred words of prose and a generated page list, but it makes the prompt a second place to edit resume facts that already live in the node folders.

Proxying to LiteLLM and letting the SPA send the OpenAI shape. The SPA would then hold the upstream contract and could not attach a prompt; the gateway would inject a key into a request body it does not read.

Keeping ADR-0006's route as a proxy and adding the handler beside it. Two live contracts for one meaning, against the constitution.

## Cost

The gateway binary grows by three packages. Tracing adds `go.opentelemetry.io/otel` and its OTLP exporter to the module. The chat is not load-bearing: a missing `llm:` block answers `503 chat_unavailable` and no other route notices, so a broken model config cannot fail a start.

Per ADR-0007 the line budget covers Go outside tests; this change spends roughly 700 of the 4,200.
